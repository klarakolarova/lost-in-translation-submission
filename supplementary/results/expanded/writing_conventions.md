# Swiss spelling and formatting conventions

Comparison of 598 completed translation pairs from motions classified as French-authored. These counts show whether the two German versions follow the same spelling, quotation and number-formatting conventions.

## Results

Number of texts containing each feature at least once; a text may contain more than one feature. These are presence checks, not counts of all occurrences.

| Feature | Official German | Machine German |
|---|---:|---:|
| ß (never used in Swiss German) | 0 | 434 |
| German quotes „ “ | 0 | 41 |
| Swiss quotes « » | 16 | 0 |
| thousands with dot (10.000) | 9 | 80 |
| thousands with space/apostrophe (10 000, 10'000) | 71 | 0 |
