# Swiss spelling and formatting conventions

Comparison of 338 completed translation pairs from motions classified as French-authored. These counts show whether the two German versions follow the same spelling, quotation and number-formatting conventions.

## Results

Number of texts containing each feature at least once; a text may contain more than one feature. These are presence checks, not counts of all occurrences.

| Feature | Official German | Machine German |
|---|---:|---:|
| ß (never used in Swiss German) | 0 | 240 |
| German quotes „ “ | 0 | 21 |
| Swiss quotes « » | 11 | 0 |
| thousands with dot (10.000) | 6 | 46 |
| thousands with space/apostrophe (10 000, 10'000) | 39 | 0 |
