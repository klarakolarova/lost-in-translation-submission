# Swiss parliamentary terminology

Comparison of 338 completed translation pairs from motions classified as French-authored. This checks whether French institutional terms are rendered using the expected Swiss German terminology.

## Institutional terms

Counts refer to texts containing the French term. A German version counts as retaining the term when an accepted form appears anywhere in that text. Alternatives show the first matching replacement; ‘other’ means no listed alternative matched, and ‘lost’ is the rule’s category for an interpellation not retained.

## Abbreviations

A French abbreviation counts as retained only when it appears without its German equivalent.

French abbreviations of Swiss authorities and laws: 65 texts contain one; the machine output keeps the French form in 52, the official translation in 0.

Most frequently retained French abbreviations (French → German; number of texts): LAMal → KVG (10), LACI → AVIG (6), CFF → SBB (5), DETEC → UVEK (4), AVS → AHV (4), OFSP → BAG (3), DDPS → VBS (3), APG → EO (3).

These are automated applications of the original terminology rules. New examples have not yet been manually checked. Term presence anywhere in a document does not guarantee every occurrence is correctly translated.
